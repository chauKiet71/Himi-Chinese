# Himi Chinese Facebook cover concepts

Five Facebook Page cover directions for Himi Chinese. Final covers are exported at 1640 × 624 px (2× the 820 × 312 desktop display size). Important copy is kept inside the center crop used by the 640 × 360 mobile preview.

- `01-workday-studio-v4-refined-mobile-crop-preview.png` — mobile crop check for the refined revision; preview only.

## Brand constraints applied

- Approved palette: Himi Red `#FF4C3B`, Himi Orange `#FF8E2D`, Mascot Black `#222222`, Clean White `#FFFFFF`.
- Approved mascot source: `public/assets/brand/himi-mascot-master.png` and `himi-sidebar-logo-transparent.png`.
- Product positioning: “Tiếng Trung cho người đi làm.”
- No invented testimonials, learner counts, rankings, or unverifiable marketing claims.
- The final text and official mascot were composed deterministically after image generation so the wording and brand character stay accurate.

## Image-generation prompt set

The five background plates were generated with the built-in image generation tool. Exact copy, logo lockup, and the approved Himi mascot were added afterward by `scripts/generate-facebook-covers.mjs`.

### 01 — Workday Studio

```text
Use case: ads-marketing
Asset type: ultra-wide Facebook Page cover background, 2.63:1 panoramic composition
Primary request: Create a premium, cheerful visual background for Himi Chinese, a practical Chinese-learning product for Vietnamese working adults.
Scene/backdrop: bright clean studio-like field with layered soft paper arches, subtle rounded learning cards and flowing ribbon forms
Subject: abstract educational atmosphere only; leave generous uncluttered negative space across the central 60% for later typography and an official mascot overlay
Style/medium: polished 3D claymorphism mixed with editorial paper cut, adult-friendly rather than childish
Composition/framing: ultra-wide, strongest decorative forms at far left and far right edges, calm open middle; all important detail inside center-safe crop
Lighting/mood: soft daylight, optimistic, focused, credible
Color palette: Himi red #FF4C3B, Himi orange #FF8E2D, mascot black #222222, clean white, pale warm tints
Constraints: no people, no animals, no penguins, no logos, no Chinese characters, no readable text, no letters, no UI screenshots, no watermark; background only for later graphic composition
```

## Regeneration

Run from the repository root:

```powershell
node scripts/generate-facebook-covers.mjs
```

The script expects the five `source-*.png` background plates in this folder and the approved mascot assets under `public/assets/brand/`.
